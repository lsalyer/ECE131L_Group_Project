# ECE131L_Group_Project
Repository for the text based game created for Group 4 in ECEL131L.

RUNNING:
Windows: Download the .exe and double click like a normal executable file!

MacOS/Linux: 
First, download the directory containing all of the files. 
Navigate to the directory containing all of the files in your terminal.
Then, use
  gcc Main.c -o TheRoom text.c images.c player.c navigation.c story.c 
to compile the game. 
Finally, use 
  ./TheRoom
to run the game!
